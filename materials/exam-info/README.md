# Exam Info

The JSON files in `edstem-quiz-threads/` are exported EdStem quiz posts.

High-value files:

- `489_quiz_scope.json`: confirmed examinable weeks and topics.
- `513_quiz_preparation.json`: staff preparation advice.
- `506_test_venue.json`: venue and workshop allocation confirmation.
- `487_actual_test_time.json`: Week 11 workshop-time confirmation.
- `475_trial_quiz_and_seb.json`: trial quiz and Safe Exam Browser note.
- `353_question_format.json`: staff note about prior MCQ format.
